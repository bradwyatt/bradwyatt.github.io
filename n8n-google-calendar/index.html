n8n Google Calendar

Personal productivity automation

Google Calendar to Todoist

n8n Google Calendar is a personal automation that connects selected Google Calendars with Todoist through a self-hosted n8n instance.

The automation:

  • Monitors selected Google Calendars for newly created events.
  • Processes events from a personal calendar and a workout calendar.
  • Retrieves event details needed to create corresponding Todoist tasks.
  • Helps organize personal schedules and workouts in Todoist.

Personal use only. This application is operated by Brad Wyatt for his own productivity workflows. It is not a publicly available service and is not offered for use by other people.

Calendar information is accessed only to run the described automation. Details selected by the workflow are used to form Todoist tasks; the precise fields can vary with the workflow configuration.
