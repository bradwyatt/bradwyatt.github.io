n8n Gmail

Personal productivity automation

Gmail to Todoist

n8n Gmail is a personal automation that connects Gmail with Todoist through a self-hosted n8n instance.

The automation:

  • Searches for Gmail conversations labeled !! TO DO.
  • Retrieves relevant message or thread information.
  • Creates Todoist tasks associated with those conversations.
  • Includes links back to the original Gmail conversations.
  • Records processed Gmail thread identifiers in an n8n Data Table to avoid creating duplicate tasks.

Personal use only. This integration is operated by Brad Wyatt for his own productivity workflow. It is not available for public use.

Gmail information is accessed only to provide the described task-creation and duplicate-prevention functionality. It is not used for advertising.
