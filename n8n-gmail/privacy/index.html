n8n Gmail

Privacy Policy

Last updated: October 8, 2026

This policy describes how the personal application n8n Gmail, operated by Brad Wyatt, accesses, uses, stores, and shares Gmail data.

Scope and purpose

The application is a personal, self-hosted n8n automation. Its sole intended user is Brad Wyatt. It finds Gmail conversations labeled !! TO DO and creates associated Todoist tasks. It is not a commercial or publicly available service.

Gmail data accessed

The automation searches Gmail labels and conversations through Google OAuth. To identify and process matching conversations, the configured workflow may access message or thread contents, subjects, sender and recipient information, timestamps, labels, metadata, thread identifiers, excerpts, and links to Gmail conversations. The precise set of fields read during each run depends on the Gmail nodes and OAuth scopes configured in n8n and has not been independently verified.

How the data is used

Gmail data is used only to find conversations carrying the !! TO DO label, create related personal tasks, link those tasks to Gmail, and prevent duplicate task creation. It is not used for advertising, retargeting, personalized marketing, credit decisions, or unrelated profiling.

Information transferred to Todoist

The workflow creates a Todoist task associated with each selected conversation and includes a link back to the original Gmail conversation. That link is confirmed to be transferred. The workflow may also map selected Gmail information into a task, but whether subjects, senders, message bodies, excerpts, or other fields are sent has not been independently verified. Those additional fields should therefore be considered potentially transferred until the workflow mapping is reviewed. Todoist processes information it receives under its own terms and privacy practices.

Storage in n8n

The n8n Data Table gmail_todoist_processed stores processed Gmail thread identifiers to prevent duplicate Todoist tasks. No specific deletion schedule has been configured or confirmed for those identifiers. Depending on the n8n configuration and the outcome of a workflow run, local execution history, logs, inputs, outputs, message details, or other Gmail information may also be retained. The current execution-history retention and automatic-pruning settings have not been independently verified.

Sharing and Limited Use

Selected Gmail information is transferred to Todoist only to provide the personal task-creation feature described above. Gmail information is not sold or transferred to advertising platforms, data brokers, or information resellers.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only to provide the user-facing personal productivity features described in this policy. Human access is limited to Brad Wyatt, the data owner and application operator, when needed to operate, troubleshoot, or maintain his workflow, or when otherwise required by law.

Authentication and security

Gmail access is authorized using OAuth credentials managed through n8n; the workflow does not require Brad Wyatt's Google password. n8n runs as a Windows service and is accessed locally at localhost:5678, but this statement is not a guarantee that the service is technically restricted to local access. Protection of the data depends on the security and access settings of the Windows computer, n8n, Google, and Todoist. No specific encryption method or absolute security guarantee is claimed here.

Retention and deletion

No specific retention period or automatic deletion schedule is promised. Processed thread identifiers, workflow data, and execution data can be managed through the local n8n installation. Tasks and Gmail links already sent to Todoist must be managed or deleted in Todoist. Revoking Google access stops future authorized access but does not automatically remove information already stored in n8n or transferred to Todoist.

Revoking access

Access can be revoked at any time from the third-party connections or security settings of the applicable Google Account. The n8n Google credential may also be disconnected or removed from the local n8n installation.

Changes to this policy

This policy will be updated if the application's handling of Gmail data materially changes. The date above identifies the latest revision.

Contact

For privacy questions or deletion assistance, email brad@BradWyatt.com.
